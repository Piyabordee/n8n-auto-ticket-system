# Stable Rules (Project)

Persistent rules for this repository:

1. Keep instructions AI-agent-friendly: clear, sequential, unambiguous.
2. Prefer small, focused edits over broad rewrites.
3. Do not create empty placeholder docs — every doc must have real content.
4. Avoid duplicating information; use links instead.
5. All workflow modifications must be documented in the relevant `docs/features/` doc.
6. Version references in documentation must be kept in sync — use `/doc-version-sync` skill after workflow changes.
7. Before pushing to GitHub, always use `/github-sanitize` to verify no sensitive data remains.
8. New documentation goes into `docs/` — follow the category structure (project, architecture, features, integrations, reference).
